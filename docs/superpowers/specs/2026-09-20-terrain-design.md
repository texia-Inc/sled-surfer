# 狙うジャンプ台・カメラ酔い対策・下り感・道幅変化と分岐・ハーフパイプ 設計書

日付: 2026-09-20。flow 設計書への追加。ユーザーのプレイ所感（「ジャンプ台は狙って乗りたい」「カメラが酔う」「もっと山を下っている感じに」「分岐や道幅の変化がない」「パイプがない」）に基づく。

## 1. ジャンプ台を狙って乗る

- `Ramp` に `x`（中心）と `width` を追加。通常ランプは幅 6 m、落差前の大ランプは幅 12 m。`x` は `[-W/2 + width/2 + 1, W/2 - width/2 - 1]` で一様（W は当該 z の道幅）。
- 物理: ランプの高さ寄与とブースト発動は `|x - ramp.x| <= ramp.width/2` のときだけ。ランプの外側は平地扱い。落差の大ランプを外すと、落差の斜面をそのまま滑り降りる（減速はしないが空中に出ない）。
- 描画: ランプ板は `ramp.width` 幅。手前 20 m にコイン列（3 枚）を置いて誘導する（`coins` に追加、ランプ中心の x）。

## 2. カメラ酔い対策

- 引き（back）と高さ（up）の速度追従量を半分（`BACK_EXTRA 3.5`, `UP_EXTRA 2.5`）、落差追加 `DROP_EXTRA 1.5`。
- 追従補間を遅く: 位置は時定数 0.6 s、注視点の高さ（ピッチ）は時定数 1.0 s、`LOOK_PITCH_SCALE 8 → 3`。ロールは使わない。
- FOV は 60 → 66（ブースト/ロケット時）まで。シェイクは衝突時のみ（ブースト・着地・破壊ではシェイクしない）。
- HUD に「カメラ演出: 強/弱」のトグル（`localStorage` に保存）。「弱」では追従量とピッチを 0、FOV 固定、シェイクなし。

## 3. 山を下っている感

- 基本勾配を `SLOPE_START 0.06 → 0.12`、`SLOPE_END 0.024 → 0.05`、`muSnow 0.12`（勾配と同値のまま、速度モデルは維持）。
- 落差: `dropChance 0.35 → 0.6`、深さ 15〜25 m。
- 起伏振幅 ×1.3。
- 遠景の谷底: 描画のみ。前方 250〜450 m の地形を粗いメッシュ（区間 5 個分を 1 枚の板、幅 200 m）で低解像度に描き、遠くの街並み（ビルの箱）を並べる。霧の far を 220 → 320 に伸ばす。

## 4. 道幅の変化と分岐

- 道幅を距離の関数 `widthAt(z)` にする。各区間に `widthStart`/`widthEnd`（20〜36 m、区間ごとに乱数、隣接区間で連続）を持ち、区間内は smoothstep で補間。物理の壁クランプ、障害物・コイン・パッド・ランプの x 範囲、地形の色分け（走行域）はすべて `widthAt` を使う。
- 分岐: `Segment.split: { z0, z1, gapHalf } | null`（確率 0.3、長さ 60〜120 m、`z0 >= 300`、落差・ランプと重ならない）。中央 `|x| < gapHalf`（3 m）に「壁」障害物（kind `wall`、hard、半径 1.6、6 m 間隔）を並べて左右 2 レーンに分ける。左右で内容を変える: 一方にコイン列 2 本、他方にランプ 1 本と氷帯。分岐の手前に看板（decor `signpost`）。
- 描画: 分岐の壁は道幅色の背の高い板（高さ 3 m）。道幅の変化は地形の走行域の色境界が滑らかに動くことで表現。崖は `widthAt` に応じて外側へ。

## 5. ハーフパイプ

- `Segment.pipes: { z0, z1, wallHeight }[]`（確率 0.3、長さ 40〜80 m、`z0 >= 200`、他の特徴と重ならない、壁高 6 m）。
- 高さ関数を `heightAt(z, x)` に拡張: パイプ区間内では `+ wallHeight * (x / (W/2))^2 * blend(z)`（blend は両端 10 m で 0→1）。`heightAt(z)` は `x = 0` を意味する。
- 物理: 接地中は `y = heightAt(z, x)`。横方向の加速度 `ax = -g * dh/dx`（x の数値微分）を `vx` に加える（パイプ外では 0）。操舵は従来どおり `vx` を上書きせず、パイプ内では `vx += steer * steerAccelPipe * dt`（`steerAccelPipe 18`）で加算にする。壁の頂点付近（`|x| > 0.85 * W/2`）で `vy_x = vx * dh/dx` が上向き 4 m/s を超えたら離陸（小ジャンプ）し、空中では `vx` を保ったまま落下、`x` を `[-W/2, W/2]` にクランプ。
- 描画: 地形メッシュは頂点ごとに `heightAt(gz, lx)` を使うので自動で U 字になる。パイプ区間の走行域は氷色。

## 6. テスト

- ramps: 幅と x が範囲内、外れた x では高さ寄与 0、乗ると発動。
- width: `widthAt` が区間境界で連続、20〜36 の範囲、障害物などが `widthAt` 内。
- split: 壁が中央にだけあり左右が通れる、区間条件。
- pipe: `heightAt(z, x)` が中央 0・壁で `wallHeight`、`ax` が中央へ向く、頂点で離陸。
- camera: 純関数 `cameraPose(target, prev, dt, mode)` を core に置きテスト可能にする（`render/camera.ts` から呼ぶ）。
